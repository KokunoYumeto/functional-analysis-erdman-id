# Jembatan spektral-kompak dan SVD O008

Folder ini memuat komponen asli terpisah yang menjembatani Bab 7, Bab 8, dan
Bab 15 edisi Bahasa Indonesia karya John M. Erdman. Teks sumber telah
mendefinisikan operator kompak, spektrum, dekomposisi polar, alternatif
Fredholm, operator Fredholm, dan indeks Fredholm. Jembatan ini tidak mengulang
Bab 15; ia menambahkan tepat tiga mata rantai yang belum tersedia sebagai satu
alur pembaca:

1. struktur spektrum tak nol operator kompak (konsekuensi
   Riesz--Schauder);
2. teorema spektral untuk operator kompak swaadjoin;
3. nilai singular dan dekomposisi nilai singular, termasuk galat pendekatan
   peringkat hingga terbaik.

Komponen ini bukan tulisan John M. Erdman dan tidak menyiratkan dukungan beliau
atau Portland State University. Komponen ditulis dengan bantuan **OpenAI Codex
gpt-5.6-sol, Ultra** atas arahan pengguna dan dilisensikan CC BY-SA 4.0.
Semua ID memakai namespace `O008-BRIDGE-CS-*`; relasi ke label sumber hanya
bersifat aditif dan tidak mengubah byte reader teks-sumber atau HTML yang telah
diterima.
