Beberapa sifat operator normal pada ruang Hilbert

ARIYANTO, Prof.Dr. Soeparna Darmawijaya

2007 | Tesis | S2 Matematika

  • Abstrak
  • File Pdf

Untuk setiap operator linear kontinu T di dalam ruang Hilbert H , maka ada dengan tunggal operator linear kontinu T * disebut operator pendamping. Operator T disebut operator normal jika T *T = TT*. Selanjutnya, tesis ini membicarakan beberapa sifat operator normal.

Given any continuous linear operator T in Hilbert space H , there is a unique continuous linear operator T * called adjoint operator. The operator T is called a normal operator if T *T = TT* . Furthermore, in this thesis we represent of some properties of the normal operator.

Kata Kunci : Teori Operator,Ruang Hilbert
